# 🔍 校园侦探：数据素养解密游戏

一个基于H5的交互式数据解密游戏，让教师体验"侦探式"的数据分析过程，从多源头数据中找到退步学生并分析原因。

## 🎮 游戏简介

### 故事背景
期末考试后，教务处发现班级里有一些学生的成绩出现了明显变化。作为班主任，你需要从多个数据源中收集线索，找出**需要关注的学生**（可能不止一人），并分析原因。

### 任务目标
1. 浏览**5个数据源**：学习成绩、家庭访谈、图书馆记录、体能数据、消费记录
2. 找出**需要关注的学生**（可能不止一人）
3. 分析每名学生的具体情况和深层原因

### 数据线索
- **30名学生**的完整数据
- 跨学科成绩变化趋势
- 家庭背景与家长访谈
- 图书馆借阅历史
- 体能健康指标（视力、睡眠、运动等）
- 校园卡消费明细

## 🎯 核心设计

### 三名需要关注的学生

经过全面分析，有三名学生需要重点关注，分别代表三种不同类型的"成绩下滑"：

---

#### 学生一：马腾（学号21）- 早恋型偏科 💕

| 维度 | 关键线索 |
|------|---------|
| **成绩特征** | 数学72→55（↓17分），物理68→50（↓18分）持续下滑；但语文75→78（↑3分），英语70→74（↑4分），呈现**典型的偏科型下滑** |
| **家庭观察** | 家长反馈"对着手机傻笑"、"总和一个女生一起走"、"魂不守舍"，明确察觉情感异动 |
| **阅读偏好** | 借阅《挪威的森林》《那些年》《匆匆那年》《致青春》等4本**爱情/青春文学作品** |
| **消费行为** | 高频消费在奶茶饮品店、西点甜品屋、文具礼品店、水果捞店等**约会场景**，总计约¥330元 |
| **健康指标** | 睡眠仅6小时（偏少），晨脉78次/分（偏高，可能因情绪波动） |

**核心问题**：早恋导致分心 + 情感波动 + 理科严重偏科

---

#### 学生二：李华（学号29）- 网络沉迷型 🚨

| 维度 | 关键线索 |
|------|---------|
| **学习成绩** | 数学65→48（↓17分），物理62→45（↓17分），英语65→52（↓13分），多科不及格且全面下滑 |
| **家庭情况** | 单亲家庭，母亲反馈"管不了他"、回家反锁房门、索要500元买网课却未学习 |
| **健康状况** | 视力从4.9骤降至4.2（严重下降），日均睡眠仅5.4小时，日均步数3200步（久坐），晨脉82次/分 |
| **消费行为** | 18天内超市消费11次，总额超400元，远高于其他同学 |
| **阅读兴趣** | 只借阅《爆笑校园》漫画，无任何学习类书籍 |

**核心问题**：疑似沉迷网络/游戏 + 家庭监管缺失 + 健康严重不良

---

#### 学生三：小明（学号30）- 家庭责任过重型 ⚠️

| 维度 | 关键线索 |
|------|---------|
| **学习成绩** | 数学95→78→62（↓33分！），物理92→75→60（↓32分！），**下滑幅度全班最大** |
| **家庭情况** | 普通经商家庭，父母开面馆忙碌，需每天照顾幼儿园妹妹，承担家庭责任 |
| **健康状况** | 体重从55kg降至51kg（瘦了4kg），日均睡眠仅5.2小时，视力轻微下降 |
| **消费行为** | 正常食堂消费，偶尔买面包牛奶，无异常消费 |
| **阅读兴趣** | 大量借阅数学/物理/文学/艺术各类书籍（17本），**学习意愿强烈但时间不足** |

**核心问题**：家庭责任过重导致学习时间严重不足

---

### 教学启示

同样的"成绩下滑"表象下，可能隐藏着完全不同的原因：

| 学生 | 类型 | 干预策略 |
|------|------|---------|
| **马腾** | 早恋型 | 情感引导而非压制，帮助平衡情感与学业 |
| **李华** | 沉迷型 | 家校协同严格监管，限制电子产品使用 |
| **小明** | 责任型 | 帮助减轻家庭负担，保护学习时间 |

**核心洞察**：多维度数据融合分析是精准教育干预的前提。

## 📱 使用方法

### 本地打开
直接在浏览器中打开 `index.html` 文件即可游玩。

### 部署到服务器供扫码访问

#### 方法1：使用 GitHub Pages（推荐）
1. 创建一个新的 GitHub 仓库
2. 上传 `index.html` 文件
3. 进入 Settings → Pages，选择部署分支
4. 获得访问链接，生成二维码供扫描

#### 方法2：使用静态网站托管
- Vercel: `vercel --prod`
- Netlify: 拖拽文件夹到 netlify.com
- 腾讯云/阿里云 OSS

#### 方法3：本地网络共享
```bash
cd detective-game
python3 start-server-simple.py

# 同网络下的设备可通过 http://你的IP:8080 访问
```

## 🛠 技术实现

- **纯前端实现**：HTML5 + CSS3 + JavaScript
- **图表组件**：Chart.js 绘制成绩趋势折线图
- **响应式设计**：适配手机端扫码访问
- **单页应用**：流畅的页面切换体验

## 🎨 游戏特色

1. **沉浸式体验**：侦探主题的UI设计，悬念感十足的引导
2. **多维度分析**：5个数据源相互印证，模拟真实教育数据分析场景
3. **灵活排序**：支持按学号、成绩、下滑幅度、借阅量等多种方式排序
4. **趋势可视化**：成绩模块提供折线图，直观展示变化趋势
5. **自由探索**：无引导性标签，教师需自主发现和分析问题
6. **复杂案例**：三名学生三种类型，考验教师的综合分析能力
7. **即时反馈**：提交结论后立即获得详细分析结果和对比分析

## 💡 教育意义

本游戏模拟了真实的"多源教育数据融合分析"场景：
- 培养教师的数据敏感性
- 锻炼跨维度关联分析能力
- 理解"数据背后的故事"
- 体验从数据到决策的完整过程
- 认识到**同样的表象可能有完全不同的原因**
