# 掌中磁场 · 螺线管手势实验室

## 启动

1. 解压整个文件夹，保留 dist、scripts 与启动文件的相对位置。
2. Mac 双击「启动.command」。如果系统阻止运行，在终端进入此文件夹执行 `bash 启动.command`。
3. 其他系统可在终端执行 `python3 scripts/serve.py`（Windows 也可用 `py scripts/serve.py`）。需要已安装 Python 3，无需额外扩展包。
4. 浏览器会打开本地地址。保留终端窗口，结束时按 Ctrl+C。

不要直接打开 dist/index.html。摄像头需要通过 localhost 或 HTTPS 访问。

## 两分钟体验

- 先拖动线圈，或点击「端面」。反转电流，比较 N/S 极和电流顺逆时针的变化。
- 点击「开启摄像头」并允许权限。右手完整入镜，拇指伸直，其余四指自然弯曲。
- 转动手腕观察线圈跟随；暂停可冻结画面讲解，切回鼠标模式会释放摄像头。

摄像头画面只在本机处理，不上传、不录制。模型、字体与运行文件已打包，正常启动后不依赖外网。建议先在实际授课电脑上试用 Chrome 或 Edge。

## 教学范围

本版只演示通电螺线管的安培定则：四指沿约定电流，拇指指向管内磁场和 N 极。绿色磁感线用于方向示意，不代表定量场强。

跟手将线圈轴与拇指方向关联，不评判四指卷曲姿态，不评分。反转电流后，磁场会指向旧拇指的反方向，需要重新核对手势。左手、丢手或不确定的姿态会显示提示。遮挡、侧面入镜和低光下的识别稳定性取决于设备与手势。

已用官方左右手图片和样本视频验证识别链路、暂停恢复、左右手与丢手反馈。仍需真人用实际摄像头检验握拳和连续转动的体验。详细结果见「验证记录.md」，依赖许可见 dist/licenses。
