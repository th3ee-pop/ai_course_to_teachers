# 《植物的一生》学情前测（三年级）

## 一、使用说明

| 项目 | 安排 |
|---|---|
| 施测时间 | 第1周、本单元第一课时开始前的课间或课前5分钟（或前一节课末） |
| 施测形式 | 口头访谈3题＋匿名纸条2题；纸条对折上交，不写名字、不评分 |
| 施测对象 | 全班45人，8个小组 |
| 目的 | 摸清种植经验、生命周期与生长条件的前概念及长周期观察的坚持性预期，为课时1的任务布置和课时2～3的讨论提供依据 |
| 结果使用 | 汇总为班级"前概念清单"，不排名、不点名；对照第8课时记录册作个体成长参考 |

## 二、前测题目

### 口头题（全班交流，举手统计）

**第1题**：你种过植物吗？种的是什么？后来它怎么样了？
> 记录：种过/没种过的比例；成功经验与失败经验各若干典型说法。

**第2题**：如果请你照顾一盆植物十几个星期，每个星期都要看它、记它，你觉得最难的是什么？
> 记录：预计"忘记""没时间""不会写"等高频困难，用于课时1任务布置（画、写、量均可）和互评设计。

### 纸条题（匿名，画、写均可，不会写字可以只画）

**第3题**：把一粒种子种进土里，以后会发生什么？请按顺序写或画出来。
> 考察生命周期前概念：是否出现"发芽—长大—开花—结果"的序列；是否出现"种子直接变大变绿"等朴素认识；是否知道"果实里有新的种子"（闭环意识）。

**第4题**：小明把一盆刚播种的花盆放进又黑又不通风的柜子里，天天浇水。你猜种子会发芽吗？为什么？
> 考察发芽条件的前概念与归因能力：能否区分"种子发芽"和"植物生长"需要的条件；是否出现"种子必须晒太阳才会发芽"的常见误概念（多数种子萌发本身不需要光，柜子里主要缺的是空气且过湿易烂种——本题重在暴露归因方式，不在标准答案）。

**第5题**：植物长大需要哪些"帮助"？想到几条写几条。
> 考察生长条件前概念：水、阳光、空气、温度、土壤（"吃土长大"）、肥料等；出现"植物吃土/喝土"说法属正常，留待课时3～4间苗看根时纠正。

## 三、分析要点与教学对策

| 可能的典型回答 | 反映的前概念 | 对应教学处理 |
|---|---|---|
| "浇水就会发芽，不用管别的" | 条件单一归因 | 课时2设置"少水/阴凉/低温"对照盆，用事实修正 |
| "种子要先晒晒太阳才肯发芽" | 萌发需要光的误概念 | 同上；对照盆之一为"避光常温"处理 |
| "种子慢慢长大变成一棵树" | 缺少阶段序列与闭环 | 课时1建立空框架生命周期图，课时7新种子对比补全闭环 |
| "植物是从土里长出来的，土会变少" | "吃土"朴素认识 | 课时4间苗观察根，讨论"水从哪里进来" |
| "芽是绿色的，两片小叶"（已见过） | 有一定经验 | 吸纳为"小组观察员"，带动组内记录 |
| "种过，但忘浇水死了/被猫刨了" | 有失败经验，易放弃 | 课时8"不顺利故事"分享，建立"失败也如实记录"的班级文化 |
| "最难的是天天记，我会忘" | 坚持性预期困难 | 采用"每周≥2次＋特别事件随时记"的低门槛任务；设班级"植物大事记"墙辅助记忆锚点 |
