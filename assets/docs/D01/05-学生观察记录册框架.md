# 《植物的一生》学生观察记录册框架

> **编写原则**：只给栏目名称与提示问题，不提供任何预先写好结论的记录模板；所有结论由学生基于自己的观察在第8课时填写完成。留白处用"____"表示由学生填写；"（提示：……）"为教师可印刷在栏目旁的引导语，语气面向三年级学生。

---

## 封面

```
        我 的 植 物 种 植 档 案
　植物名称：____________
　我的姓名：____________　所在小组：____________
　开始日期：____年____月____日
　（贴上或画上我播种那天的样子）
```

## 使用小贴士（记录册第1页，课上师生共同阅读）

- 什么时候记？**每周至少记2次**；发生特别的事（发芽了！开花了！）随时记。
- 怎么记？**画一画、写一写、量一量**，哪种方便用哪种；不会写的字可以用拼音或问老师。
- 三条约定：
　1. 我看到什么样，就记什么样；
　2. 不确定时，先画下来；
　3. 没发芽、叶子黄了、被碰断了——也要如实记下来。

## 第1页：播种卡（第1课时完成）

- 我的种子长什么样？（画一画，写一写：颜色、形状、大小、摸起来的感觉）
- 我们把它种在____________，埋了大约多深？浇了多少水？
- 我猜____天后它会发芽。（到时候来验证！）

## 第2页起：每周观察记录页（每周1页，至少写2次）

> 每次记录填写：

- 日期：____月____日　第____次观察
- 我看到的：（画一画整棵植物的样子）
- 我量到的：它现在大约____厘米高；有____片叶
- 我的新发现或我想问：____________
- 这一周我为它做了：____________

> （页脚提示语：画不下可以贴照片或拓印一片叶子。）

## 特别事件页（随记录页穿插，用★标出，随到随记）

> 每个特别事件一页，栏目相同：

- ★发芽的那天　★第一片真正的叶子　★第一朵花　★第一个果实　★果实裂开的那天

- 日期：____月____日
- 我看到了：（画＋写）
- 我想说：____________

## 阶段小结页（共4页：幼苗期之后／开花之后／结果之后／收获之后各1页）

> 每页栏目：

- 这段时间，我的植物最大的变化是：____________
- 从播种到现在大约过了____天。
- 这一阶段我还想知道：____________

## 我的种植问题银行（随记录页穿插）

- 我遇到的问题或奇怪的事：____________
- 我猜可能是因为：____________
- 我打算怎么做（问老师／查书／做个小试验）：____________

## 我和同伴的对照盆记录页（第2课时起，每周看1次）

- 我们组的对照盆和正常盆有什么不一样：____________
- 这次看到的变化：____________

## 植物的一生整理页（第8课时完成）

- 我的植物从一粒种子到结出新种子，一共用了____天。
- 从播种到发芽用了____天；到开花用了____天；到结出新种子用了____天。
- 生命周期圆环图（已印好空框与箭头，框内由学生填写阶段名、画出该阶段的样子）：

```
　　┌→［　　　］→［　　　］→［　　　］→［　　　］→［　　　］┐
　　└──────────────← 新的种子 ←──────────────────────┘
```

- 我的植物一生中，我印象最深的一件事是：____________
- 如果再种一次，我想改变的地方：____________

## 互评页（第8课时使用）

- 我看了____________（同伴姓名）的记录册，我想送出：
　□ 坚持星（记得勤）　□ 仔细星（看得细）　□ 真实星（实话实说）　□ 会想星（爱提问）
- 我想对他说的一句话：____________

## 我的收获三句话（第8课时）

- 我学会了：____________
- 最难忘的是：____________
- 我想接着研究：____________

---

**印刷说明（教师用，不印发学生）**：
- 建议规格：A4横开、8～10个双面页＋空白观察页8～10页，骑马钉；封面留涂色区。
- 每周观察页数量应略多于实际周数，允许学生多用页（画大开页）。
- 全册仅栏目与提示，不含任何阶段名称结论（"发芽—幼苗—开花—结果"等词由学生在整理页自主填写），以确保记录任务的评价效度。
