# 《植物的一生》8课时活动详案与记录要求

> 每课时40分钟。周次为建议值，可按生长进度整体前后移动（见文件①第五部分）。所有课时的记录均写入学生观察记录册（框架见文件⑤），记录册只给栏目与提示，不含任何预写结论。

---

## 课时1　种子与播种——它的一生开始了（第1周｜播种日）

**课时目标**
1. 观察并描述凤仙花种子的外部特征（颜色、形状、大小、手感）。
2. 参与讨论种植计划并亲手播种，明确后续"每周至少看两次"的任务。
3. 建立"植物的一生"的整体印象（知道要经历种子、发芽、长大、开花、结果，最后再得到新的种子）。

**材料准备**：凤仙花种子（每组一小碟＋备用）、花盆与土、放大镜、标签牌、记录册（人手一本）、成熟凤仙花植株照片或干果实。

**课前检查**：土提前分装；桌面铺报纸；检查种子无霉变。

**活动过程（40分钟）**
1. **聚焦（5分钟）**：出示一粒种子与成熟植株（带果）照片："这棵大植物和这粒小种子之间，发生过什么故事？"揭示单元主题与核心任务——"种一株植物，讲它的一生"。
2. **观察种子（10分钟）**：各组用放大镜观察种子：看（颜色、形状、大小）、摸（滑不滑）、比（和米粒比大小）。在记录册"播种卡"上画一画、写一写。全班交流后翻看教师手心的干果实——摇一摇，里面就是这样的种子。
3. **讨论种植计划（8分钟）**：围绕"种在哪里？埋多深？浇多少水？需要什么？"收集学生想法，教师逐条写在"我们的种植计划"大白纸上，**不评判对错**，留待后面几周用事实检验。
4. **分组播种（12分钟）**：每组一盆，播3～5粒，覆薄土，浇透水，插标签（组名＋播种日期）。商量花盆摆放位置。
5. **小结与任务布置（5分钟）**：翻看记录册栏目，明确任务：**每周至少看两次、记两次**；特别的事（发芽！）随时记。预告："两周后我们回来交流第一件大事。"

**记录要求**：完成"播种卡"——种子画像（画＋写）、我们种在哪里、我猜____天后发芽。

**课后观察任务**：每天路过看一眼；回家和家人聊聊"你种过什么植物"。

**调整提示**：若当周播种来不及（如器材未到），可改为课上完成播种卡与计划讨论、课后教师协助播种，日期如实写。

## 课时2　发芽了（第3周｜播种后第2周前后）

**课时目标**
1. 交流并统计发芽情况，如实记录"发芽日期"这一关键数据。
2. 分析未发芽可能的原因，参与补种，初步体会"对照"的想法。
3. 观察并画出发芽早期的样子。

**材料准备**：各组盆栽、放大镜、备用种子与备用盆、班级统计大表。

**课前检查**：前一天巡视各组发芽情况，做到心中有数；准备2～3个"低温""缺水"对照盆（提前几天布点：一盆放不浇水，一盆罩袋放阴凉处）。

**活动过程（40分钟）**
1. **聚焦（5分钟）**："两周过去了，我们的种子怎么样了？"
2. **交流与统计（10分钟）**：各组汇报：发了没有？几棵？全班把数据汇总到大表上（发芽数/播种数）。**特别关注未发芽组**，请他们说说可能的原因（水多了？太冷？埋太深？）。
3. **对照探究：发芽需要什么（12分钟）**：出示教师准备的对照盆，观察差异并讨论："这两盆为什么不一样？"学生提出猜想（水、温度、光等）。各组补种一小盆，选一个"和正常不一样"的条件（如少浇水/放阴处），插牌标注，以后每周看一次。
4. **观察芽（8分钟）**：用放大镜看芽：芽是什么颜色？先钻出来的是什么？像什么？在记录册上画下来。
5. **小结（5分钟）**：发芽是植物一生的第一个关口；"发芽那天"的日期是重要数据，漏记的可以估记并标注"估"。

**记录要求**：发芽日期、芽的画像与描述；未发芽组补记原因猜测与补种决定；本组对照盆的安排。

**课后观察任务**：观察对照盆变化；继续每周至少记2次。

**调整提示**：若普遍未发芽（低温），本课顺延1周，先按上述环节3上"发芽需要什么"，用补种争取时间。

## 课时3　幼苗长大了（第5周｜播种后第4周前后）

**课时目标**
1. 观察幼苗，认识真叶，描述叶的颜色、形状与排列。
2. 学会用直尺测量株高的规范方法（从土面到最高叶尖，取整厘米）。
3. 结合对照盆的结果，讨论植物生长需要的条件；落实活动周养护交接。

**材料准备**：直尺（人手一把）、放大镜、各组盆栽与对照盆、记录册。

**课前检查**：确认对照盆差异明显；准备间苗说明（下节课用，提前告知）。

**活动过程（40分钟）**
1. **聚焦（5分钟）**：把第1周的种子画像和现在的苗放在一起对比："变化有多大？"
2. **观察幼苗（10分钟）**：数一数有几片叶；看叶的形状、叶尖、叶脉；找一找有没有刚冒出来的小叶。在记录册画一棵"我组的幼苗"（整棵＋单独一片叶）。
3. **学习测量（12分钟）**：教师示范：尺竖直贴茎、从土面量到最高叶尖、眼睛平视读数、记整厘米。每人量自己负责的植株（每组分工认领），把数据记入本周记录页。强调：**量出来的数是什么就记什么**。
4. **讨论：植物长大需要什么（8分钟）**：回顾对照盆——"现在能看出什么了？"结合学生生活经验，汇总生长条件（水、阳光、空气、合适的温度），写在大白纸上（这是全班共同结论，不是印给学生的）。
5. **养护交接＋小结（5分钟）**：下周是学校活动周，不上科学课。落实各组浇水值日与"土面发干才浇"原则，明确记录照常进行。

**记录要求**：幼苗画像、株高（厘米）、叶片数；本周记录页"我为它做了____"。

**课后观察任务**：活动周期间坚持观察记录；回来时带来"最大的发现"。

**调整提示**：若长势偏慢，测量仍照做（数据小也是数据），株高对比分析移到课时4完成。

## 课时4　茎撑起了植物（第7周｜播种后第6周前后）

**课时目标**
1. 用两次株高数据对比，发现快速生长期，说出"长高主要靠茎"。
2. 观察茎的颜色、粗细、"节"，感受茎的支撑作用。
3. 通过间苗，观察完整根系，初步认识根的作用（吸水、固定）。

**材料准备**：直尺、放大镜、上周株高数据（教师汇总表）、间苗操作示范盆、小铲/竹签。

**课前检查**：确认各组苗已拥挤（每盆3～5株），间苗可行；准备间下来的苗的处置方案（观察用→移栽到校园边角地或带回家）。

**活动过程（40分钟）**
1. **聚焦（5分钟）**：活动周过去了，我们的植物还好吗？谁在照顾？先请值日组汇报。
2. **数据对比（10分钟）**：重新测量株高，与第5周数据并排记。找一找：这两周长了多少厘米？全班交流哪组长得快。追问："长高，是植物的哪个部分在长？"引出**茎**。
3. **观察茎（8分钟）**：看茎的颜色、粗细变化（下粗上细？）、摸一摸；轻碰植株感受"是茎把它撑起来的"。在记录页上给茎画个特写。
4. **间苗与看根（12分钟）**：讨论"一盆里挤了这么多株会怎样"，学习间苗：每组留2～3株壮苗，其余小心连根拔起。**用放大镜观察拔下来的整株**：土下面有什么？根长什么样、有多少？在记录页画一画根。间下的苗可移栽到校园地块或带回家继续养。
5. **小结（5分钟）**：根在土里吸水、抓土固定植株；茎支撑并把水往上送；叶晒太阳制造养料（定性）。这些都可以在后续观察中继续验证。

**记录要求**：株高对比数据（两周并排）、茎的特写、根的画像；如果间苗时弄伤了苗，也如实记下来。

**课后观察任务**：移栽的苗能活吗？一周后记录结果。

**调整提示**：若苗过密影响生长提前发生，间苗可提前到课时3末尾；本课时则多留时间做数据对比与根的观察。

## 课时5　开花了（第9周｜播种后第8周前后）

**课时目标**
1. 观察花的颜色、形状、花瓣数量与花心里的结构（简化：花瓣、花心）。
2. 发现花粉（轻碰花心有黄色粉），了解花是植物"生宝宝"的阶段。
3. 推想"花谢以后会怎样"，带着预测持续观察。

**材料准备**：放大镜、教师备用盆栽（保证有花可看）、每组一朵新鲜花＋一朵谢了的花、白纸（接花粉用）。

**课前检查**：巡视各组现蕾开花情况；准备教用备用植株，防止个别组无花。

**活动过程（40分钟）**
1. **聚焦（5分钟）**："植物悄悄进入了下一个阶段——你发现什么了？"（花苞/花）
2. **观察花（15分钟）**：看颜色形状→数花瓣→用放大镜看花心里有什么→轻碰花心，白纸上抖一抖，看到黄色粉末（花粉）。在记录册画一朵花（整体＋花心特写）。提醒：只观察自己组的"观察花"，不乱摘。
3. **对比与推想（8分钟）**：发每组一朵谢了的花：花瓣掉了，花底下有什么变化？（鼓起的小鼓包）猜一猜：它会变成什么？
4. **讨论传粉（7分钟）**："花粉怎么从这朵花跑到那朵花？"联系生活（蜜蜂、蝴蝶、风）。教师定性说明：花粉到了"花妈妈"身上，花谢后那个鼓包才会慢慢长成果实。
5. **记录与小结（5分钟）**：记下"第一朵花"的日期和目前的花数。预告：下次课见分晓。

**记录要求**：第一朵花日期、花的画像、花心特写；我的推想"花谢后会____"。

**课后观察任务**：数花苞和开花的数量变化（只数不摘）；看看有没有小昆虫来访。

**调整提示**：若开花普遍推迟，本课顺延1周，空出的一周做机动观察交流（各组展示记录册、互提建议），不新增课时。

## 课时6　结果了（第11周｜播种后第10周前后）

**课时目标**
1. 观察幼果的形状、颜色、大小，发现果实由花谢后的"鼓包"发育而来。
2. 通过解剖幼果，发现"果实里有种子"。
3. 推猜果实成熟后的变化（颜色、开裂），继续观察验证。

**材料准备**：放大镜、教师解剖用果实（幼果＋较熟果实各数枚）、垫板与小刀（教师操作）、各组盆栽。

**课前检查**：确认各组结果情况；准备教用备用果实（可从教师备用植株取）。

**活动过程（40分钟）**
1. **聚焦（5分钟）**：回看上次的推想——花谢了，花的位置现在是什么？
2. **观察幼果（12分钟）**：找一找盆里最大的果实和最小的果实（可能是刚谢花的）。看颜色、形状、摸表面；量一量最大的果实大约多长（厘米）。在记录册画"果枝"：一段带果的枝。
3. **解剖观察（10分钟）**：教师在实物投影下解剖幼果：横切、纵切，看里面——一排白色的小籽！学生用放大镜传看各组发到的小块。讨论：这些小籽长大后会怎样？
4. **推猜成熟（8分钟）**："这个绿色的果实，再过两周会变成什么样？"各组把猜测写/画在记录页（不评判，两周后验证）。
5. **联系生活＋小结（5分钟）**：我们吃的哪些蔬菜水果也是"果实"？它们里面有种子吗？（番茄、黄瓜、苹果……）果实是装种子的"盒子"。记下"第一个果实"的日期。

**记录要求**：第一果日期、果枝画像、最大果实长度；我的猜测"成熟后会____"。

**课后观察任务**：每周记录果实颜色、大小的变化；看看有没有果实先变黄。

**调整提示**：幼果不足时多用教师备用植株；青果留待自然成熟，供课时7采收。

## 课时7　新的种子（第13周｜播种后第12周前后）

**课时目标**
1. 采收成熟果实，剥出并数清种子。
2. 把新种子与第1周观察的种子对比，建立"一生"的完整闭环。
3. 汇总全班关键时间数据（发芽、开花、结果各用了多少天），形成"植物的一生"时间轴。

**材料准备**：采收用小剪刀/直接手摘、白纸（剥籽用）、纸袋或信封（装种子）、第1周"种子画像"（记录册）、班级时间轴大表。

**课前检查**：巡视果实成熟度；准备少量已开裂的干果（教师备用），防止雨水或晚熟影响采收。

**活动过程（40分钟）**
1. **聚焦（5分钟）**："果实变成什么样了？"（变黄、变干、有的已经裂开卷起）轻轻一捏——种子蹦出来了！
2. **采收与数种子（15分钟）**：各组小心采收成熟果实，在白纸上剥开、数种子：一共有多少粒？挑最饱满的10粒晒干装袋，贴标签（组名＋日期）。**注意：轻拿轻放，种子会弹飞**。在记录页写清数量。
3. **新旧对比（8分钟）**：翻开第1周的播种卡，把新种子和当时的种子放在一起比：一样吗？哪里一样、哪里不一样？——我们用一粒种子，换回了满捧种子，这就是"植物的一生"。
4. **汇总时间轴（7分钟）**：全班把关键日期报上来，算一算：从播种到发芽用了几天？到开花？到结出新种子？填在班级时间轴大表上，抄进记录册"一生整理页"。
5. **小结与预告（5分钟）**：下节课开"植物的一生讲述会"，每人想好"我的植物最难忘的一件事"，带好记录册。

**记录要求**：种子数量、新旧种子对比（画/写）、时间轴数据。

**课后观察任务**：把几粒种子带回家给家人讲"它的一生"；留意路边、家里的植物现在处于哪个阶段。

**调整提示**：青果尚多时课上剖少量青果对照，其余留待自然成熟由学生课后采收补记；本课与课时8不顺延。

## 课时8　植物的一生——讲述与总结（第14周｜全程回顾）

**课时目标**
1. 整理观察记录册，用自己记录的证据补全生命周期图。
2. 用数据与图画讲述"我种的植物的一生"。
3. 通过互评与反思，体会长期观察与如实记录的价值。

**材料准备**：各组盆栽（含保留的干果枝）、生命周期空框圆环图（记录册内页）、"植物大事记"墙、互评星星贴纸。

**课前检查**：提前一天提醒带记录册；打印互评页。

**活动过程（40分钟）**
1. **聚焦（5分钟）**：黑板上贴出从种子到新种子的照片时间轴："十三周，我们一起走完了它的一生。"
2. **整理（15分钟）**：完成记录册"植物的一生整理页"：补全生命周期圆环图（在空框里写阶段名、画该阶段的样子、标上"用了____天"）；写阶段小结。组内互相翻看记录册，交流"你记到了我没注意到的事"。
3. **讲述会（12分钟）**：每组推1名代表，用30～60秒＋记录册讲述"我们组植物的一生"（鼓励用数据："第9天发芽""第58天开花"）。其他组提问补充。特意安排1～2个"不顺利故事"（没发芽、断过茎）的分享，教师点评：**如实记录失败，同样是好科学**。
4. **互评与反思（8分钟）**：按量规给同伴记录册贴星（坚持星/仔细星/真实星/会想星）。完成"我的三句话"：我学会了____；最难忘____；如果再种一次，我想____。
5. **延伸与结束（5分钟）**：处理收获物——饱满种子留作"传给下一届三年级的种子"或假期种第二茬；观察记录册放进步袋。

**记录要求**：一生整理页全部完成；互评页贴星并签名。

**课后观察任务（单元延伸）**：假期用自己收的种子再种一茬，做一本新的记录册；持续留意身边植物处在"一生"的哪个阶段。

**调整提示**：若单元因故整体后延，本课可在第15周进行，学期仍留有机动余地。
