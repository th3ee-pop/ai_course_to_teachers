# 《植物的一生》第一课时完整教案

## 课题：种子与播种——它的一生开始了

| 项目 | 内容 |
|---|---|
| 学科/年级 | 小学科学 / 三年级 |
| 课时 | 第1课时，40分钟（建议第1周） |
| 课型 | 单元起始课（观察＋实践） |
| 班级情况 | 45人，8个小组；学生第一次经历长周期种植观察 |

## 一、教学目标（按2022年版课标四维核心素养表述）

1. **科学观念**：知道种子是植物一生的起点，植物一般会经历种子、发芽、长大、开花、结果、结出新的种子；能描述凤仙花种子的颜色、形状、大小等外部特征。
2. **科学思维**：能基于观察比较种子与成熟植株，提出关于"种子会变成什么"的猜测；能对"种在哪里、怎么种"提出自己的想法。
3. **探究实践**：会借助放大镜按"看—摸—比"的顺序观察种子并画下来；能在小组合作中完成播种（播种、覆土、浇水、插标签）。
4. **态度责任**：愿意承担后续十几周的观察记录任务，初步约定"如实记录、坚持记录"的规则。

## 二、教学重难点

- **重点**：有序观察种子的外部特征；亲手播种并明确后续观察记录任务。
- **难点**：建立"一粒种子将要经历完整一生"的整体印象（学生易只关注"发芽"一步）；理解记录册"只记我看到的，不抄别人的"这一要求。

## 三、教学准备

**教师**：凤仙花成熟植株照片（或干果实物）、干果数枚、班级"种植计划"大白纸、各组观察碟、示范盆一套、湿巾/洗手安排、记录册45本。
**小组**：种子一小碟（约10粒）、花盆1个（已装土八分满）、放大镜1～2把、标签牌、浇水瓶（共用2～3个）。
**场地**：桌面铺旧报纸；就近水源；花盆摆放窗台已预留位置。

## 四、教学过程（40分钟）

| 环节 | 时间 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|---|
| （一）情境聚焦，揭示主题 | 5′ | 出示一粒种子与成熟植株照片："这棵大植物和这粒小种子之间，发生过什么故事？"板书课题，介绍单元核心任务：种一株植物，用记录册讲"它的一生" | 观察对比，自由发言：可能是它的"小时候"？ | 由强烈反差引发好奇，建立"一生"的整体期待 |
| （二）观察种子 | 10′ | 发种子；提示观察顺序：先用眼看（颜色、形状、大小），再用手摸（滑不滑），再和米粒比大小；示范放大镜用法；出示干果摇一摇——"咔啦"声就是里面的种子 | 用放大镜按顺序观察，在记录册"播种卡"上画一画、写一写；组内交流自己的发现 | 学习有序观察；把"种子"这一起点的样子固定下来，供第7课时新旧对比 |
| （三）讨论种植计划 | 8′ | 提问：种在哪里？埋多深？浇多少水？它以后需要什么？把各组想法**原样**记在班级"种植计划"大白纸上，不评判对错 | 各组讨论并汇报；发现组与组想法不一样时互相质疑 | 暴露前概念，制造"以后用事实检验"的悬念；避免教师直接告知结论 |
| （四）分组播种 | 12′ | 示范：扒浅沟→每盆放3～5粒→覆一指节薄土→浇透→插标签（组名＋播种日期）；巡视指导覆土深度与浇水量 | 分组按步骤播种，明确组内分工（执粒、覆土、浇水、写标签）；商量花盆放窗台哪个位置 | 亲手播种产生"这是我们的植物"的责任感；播种日期成为全单元时间轴起点 |
| （五）小结与任务布置 | 5′ | 翻开记录册逐栏认识；宣布任务规则：**每周至少看两次、记两次；发芽等特别的事随时记；看到什么记什么，没发芽也要如实记**；预告两周后交流第一件大事 | 齐读任务口令；在封面写姓名、组名、播种日期 | 低门槛、高频率的记录约定是长周期任务成败关键 |

## 五、板书设计

```
        植物的一生
   种子 → ？ → ？ → ？ → ？ → 新的种子
  （今天种下）                 （我们要收回来）
   播种日期：____年____月____日
   任务：每周至少看两次、记两次
```

（"？"处空着，由学生在一周周观察后陆续补全，第8课时完成闭环。）

## 六、记录要求（本课时）

完成记录册"播种卡"三栏：
1. 我的种子长什么样（画＋写：颜色、形状、大小、手感）；
2. 我们把它种在____，埋了多深、浇了多少水；
3. 我猜____天后会发芽（第2课时验证）。

## 七、课后延伸

1. 每天路过窗台看一眼，不用每天浇水（土面发干才浇）。
2. 回家和家人聊一聊：家里或老家种过什么植物？后来怎么样了？下节课带来一句话分享。
3. 留意上学路上的植物：它们现在有花或果实吗？

## 八、安全与注意事项

- 接触土壤后统一洗手（湿巾备用）；种子不可入口。
- 播种环节提前分装土、铺报纸控制扬尘与桌面整洁。
- 对植物/花粉过敏的学生负责记录与摄影角色。
- 提醒浇水原则："发干才浇、浇则浇透"，防止第1周因过度浇水烂种。

## 九、差异化与预设

- 动作慢的小组：教师提供已开浅沟的备用盆，保证12分钟内完成。
- 若有学生说"我以前种过都死了"：正面回应——这次全班一起养，失败也如实记，学期末"失败故事"同样上台讲。
- 时间不足预案：环节（二）的组内交流压缩，保证播种完整；播种卡未画完的带回家补。
