# 《沉与浮》研讨课课堂实录（模拟·匿名）

> 说明：本文为教研培训用模拟逐字稿，发言人均以编号呈现，不对应任何真实师生。课题为小学科学"沉与浮"单元研讨课，五年级，时长40分钟，8个实验小组。正文（不含自查清单）纯汉字约4200字、含标点约5000字，文末附统计自查清单。

## 课堂实录

### 一、导入回顾（第1—10分钟）

（讲台上放着一只装水的玻璃水槽，教师手里拿着一枚回形针和一艘铁皮小船模型，黑板上贴着上节课的班级记录单。）

师：同学们，上节课我们观察了物体在水中的沉浮，谁还记得，我们当时试过哪些东西，哪些沉下去了、哪些浮着？

生1：回形针沉了，泡沫块浮着。

生2：还有橡皮，橡皮也沉。

师：都记得很准。这枚回形针是铁做的，放进水里会沉；那这艘小船也是铁做的，为什么能浮起来？

生3：因为它是空的，里面有空气，空气比水轻，就把船托起来了。

（刚才演示时，回形针"叮"一声沉了底，铁皮小船稳稳浮在水面上，学生看得目不转睛。）

师：这是今天冒出来的第一个重要想法，老师先把它记在黑板角上，等会儿要回来检验。我们不急着下结论，先继续回顾。看记录单，上节课我们还试过木块和石块，它们的结果分别是什么？

生4：木块浮在水面上，石块沉到水底了。

师：说得很完整。那当时我们判断一个物体是沉还是浮，标准是什么？

生5：物体碰到水槽底就是沉，漂在水面上就是浮。

生6：我有补充。有一片小木块一半露在水面上、一半浸在水里，但是没碰到底，我们也算它浮。

师：这个补充很关键——只要不碰底、贴着水面漂，都算浮。记录的时候，沉和浮分别用什么符号表示？

生5：沉画一个向下的箭头，浮画一个向上的箭头。

师：对，符号要统一。除了回形针、泡沫块、橡皮、木块、石块，我们还往水里放过别的东西，谁能补充？

生2：蜡烛！蜡烛是浮的，我当时特别惊讶，它摸起来比石块还重呢。

生1：塑料瓶盖也浮着，漂在水上像一条小船。

师：大家记录得都很仔细。下面这个问题很关键——上节课，橡皮泥放进水里，结果怎么样？

生7：沉了，"咚"一下就到底了。

师：当时我们是把橡皮泥怎么放进去的？

生7：揉成一团圆圆的实心球，直接放进去的。

师：好，这个细节请全班记住，等一下要用。上节课下课前，老师在黑板旁边留了一个问题，谁还记得是什么？

生4：能不能让沉下去的东西浮起来。

师：对，就是它。今天每个组的材料盒已经打开了，谁能完整说一说里面有哪些材料？

生8：一块橡皮泥、几张铝箔纸、一小块泡沫、三颗玻璃珠，还有一个装满水的水槽。

师：材料清点清楚。现在回到生3的想法——他说铁船里有空气，空气比水轻，所以船浮着。老师手里有一枚小铁钉，它比这一大槽水轻得多得多，按"轻就浮"的说法，它应该稳稳地浮在水面，可它一放手就沉底了。谁来解释这个矛盾？

生3：因为铁钉是实心的，里面没有空气。

师：那我们暂且把它记作今天的"猜想一"：有空气的东西能浮，没有空气的就沉。今天我们就来讨论一个问题——沉和浮到底跟什么有关，特别是：同一块橡皮泥，不改轻重、不加任何别的东西，只改变形状，能不能让沉的浮起来。大家先想一想自己的办法，写在实验单"我的猜想"一栏里。

（学生安静思考、填写，约一分钟。教师板书课题"沉与浮"，在黑板右侧画出"证据栏"。）

### 二、小组实验：沉浮探究（第11—28分钟）

师：实验分三步，要求听清楚。第一步，把材料一样一样轻轻放进水里，把沉浮结果记在表格里；第二步，重点研究橡皮泥——先让实心球沉一次，记下来，再想办法只改变形状，让它浮起来；第三步，浮起来以后，往碗里轻轻放玻璃珠，看看最多能装几颗。三个注意：轻拿轻放，水面要保持平静；水洒出来马上用抹布擦；每次把橡皮泥拿出水面之前，先看一看它浸在水里的部分有多大。现在开始。

（学生分组实验，教师巡视指导。）

师：（走到第3组）你们第一步测完了，哪些材料沉了、哪些浮着？

生9：玻璃珠沉，泡沫浮，铝箔平着放是浮的。

生10：老师，我们组的铝箔揉成一团就沉了，展开摊平又浮起来了。

师：这个对比太宝贵了，一会儿汇报一定要讲给全班听。追问一下，你们当时为什么想到把铝箔又展开又揉团？

生10：因为上课的时候讨论铁船是空心的能浮，我们就想试试，铝箔变一变样子，沉浮会不会跟着变。

师：会做实验，更会想问题——材料不变、只变形状，这正是今天的关键。（走到第5组）橡皮泥实心球放进去，结果怎样？

生11：沉得特别快，直接躺到水槽底上了。

师：你们后来把它改成了什么形状，放进水里以后看到了什么？

生11：捏成了一只小碗，平平地放到水面上，它就浮住了，跟一片树叶似的。

师：好，先记下这个结果。往碗里放一颗玻璃珠试试，放的时候注意观察碗往下沉了多少。

（第5组操作，碗下沉了一小截，没有沉底。）

生11：放一颗还浮着，放到第三颗，水漫过碗边，整只碗就慢慢沉下去了。

师：把"最多装两颗"记在表格里。第5组待会儿汇报，要把捏碗的完整过程一五一十讲出来。已经成功的组，把碗里外擦干，用天平称一称：碗和刚才那个实心球比一比，轻重有没有变化，把结果记下来。

（第6组的橡皮泥捏成了"饺子"形，边上没有捏高，放进水里晃了两晃就斜着沉了下去。）

生22：老师，我们的沉了。它像一艘漏水的船，歪着身子，一点一点往下掉。

师：先别急着捞。注意看，水正从矮的那条边一点一点漫进去。

生23：我看见了，边上太矮，水一漫进去，碗里就越来越重，就沉下去了。

师：看明白了就动手改——把碗口再捏高一些，橡皮泥擦干，放的时候放平，再试一次。

（第6组重新改造，第二次小碗稳稳浮住，两个学生击掌。）

（另一边，第2组正争论要不要用铝箔给橡皮泥折一只小船。）

生26：老师，我们想用铝箔折一只小船，让橡皮泥坐在船里浮起来，这样算不算成功？

师：这个想法很妙，不过今天的任务是让橡皮泥自己浮起来，铝箔小船先记在记录单背面，下一节课专门研究"船"。（各组继续实验。第2组、第7组先后让橡皮泥碗浮起来，教室里响起小声的欢呼。教师逐一查看记录单，提醒失败的小组把碗擦干再试、放的时候放平。）

### 三、汇报交流（第29—36分钟）

师：请各组把材料放回盒子里，坐正。今天我们来讨论一个问题——同一块橡皮泥，实心球沉、捏成碗就浮，道理到底在哪里。先请第5组汇报。你们第一次把橡皮泥放进水里，看到的是什么？

生7：我们组拿的是蓝色橡皮泥，先把它揉成一个实心的小圆球，跟玻璃弹珠差不多大，放进水里"咚"一下就沉到水槽底，躺在那儿一动不动。我们想让它浮起来，就把它捞出来，先擦干水，用手掌把它压扁，压成一张厚厚的圆饼；再把饼的边上一圈一点一点往上捏，捏高一点，再捏高一点，最后捏成一只小碗的样子，碗底留得厚一点，不然容易破。放的时候要平平地、轻轻地放，不能扔。第一次我们有点着急，碗是斜着下去的，水从矮的那边灌进去，碗一下子就翻了、沉了。第二次我们重新把它擦干、捏好，稳稳地平放在水面上，它就浮住了。后来我们往碗里放玻璃珠，放两颗还浮着，放到第三颗，水漫过碗边，整只碗就慢慢沉下去了。我们还发现，碗口捏得高一点，就能多装一颗珠子。

师：先沉、改造、再浮，中间还失败了一次又重来，这个汇报非常完整。老师追问一句——形状大变样之后，轻重到底变没变，要用证据说话。刚才有的组用天平称过了，谁来说说你们看到的现象？

生12：我们称了，碗和实心球一样重，指针几乎没动。

师：一样重。这条证据太重要了，写进黑板右边的证据栏——"变形状，没变轻重"。生3，现在轮到你了。开头你说铁船能浮是因为船里有空气，现在橡皮泥碗也浮起来了，碗里凹下去的地方，正好也兜着空气。结合今天的实验，你是怎么想的？

生3：我还是觉得和空气有关系。你们看，碗是凹进去的，凹的地方装满了空气，放进水里以后，这些空气就被关在碗里面跑不出去。空气比水轻很多，就像游泳圈一样，一大团轻飘飘的空气垫在碗底下，水托着这么轻的东西，当然要把它顶上去，碗就浮起来了。铁船那么重还能浮，也是因为船舱里装的大部分是空气。而且我们组试过，把碗翻过来扣着放，空气一下子跑光了，碗里灌满了水，它马上就沉。实心球里面一点空气都没有，它就沉。所以我觉得规律就是：里面兜着空气的能浮，没有空气的就沉。

师：生3把自己的想法讲得清清楚楚，还自己找了证据来支持，这正是科学家讨论问题的方式。不过科学讲究证据，我们一条一条来对。刚才第1组做的铝箔实验，正好跟这个说法碰上了。第1组，把你们的发现讲给大家听。

生10：我们把铝箔摊平，平放在水面上，它是浮的；把它揉成一个紧紧的团再放，它就沉了。可是那个铝箔团里面，其实也裹着一小包空气，并不是完全实心的。

生9：我补充，同一张铝箔，摊平和揉团，轻重也是一样的，我们用手掂不出差别。

师：两条新证据，都写进证据栏——"铝箔团裹着空气，也沉了""铝箔摊平和揉团一样重"。这样一来，猜想一就有点站不住了。我们再看一个演示。这是溢水杯，把水加到刚好会溢出来。（演示）实心球放进去，接到的水只有小半杯；捞出来，把小碗轻轻放进去，接到的水有满满一杯。同样重的两块橡皮泥，球只排开小半杯水，碗排开的水多得多。为什么排开的水多了，它就能浮起来？

生13：我猜水有一个往上托的力气。碗在水底下占的地方大，被它挤开的水就多，水想跑回原来的位置，就一个劲儿往上托它。要是往上托的力气比碗的重量大，碗就浮起来了；实心球占的地方小，水托它的力气小，托不住它那么重，就沉了。

师：讲得真好。水确实会对泡在水里的物体有一个向上的托力，科学上把它叫作浮力；排开的水越多，这个向上的托力就越大。橡皮泥球和碗一样重，但碗排开的水多得多，水托它的力超过了它的重量，它就浮住了。再看铁船，船做成空心确实非常重要，但不是空气像一只手一样把船往上托，而是整条船——铁皮加上围出来的那一大块空地方——合在一起，比跟它同样大的一整团水要轻，所以水托得住它。橡皮泥碗也是同样的道理：碗加上碗里兜住的空间，比同样大的一团水轻。现在我们手上有四条证据了。第7组也来汇报一下你们装玻璃珠的数据。

生24：我们组最多装了三颗。我们的碗捏得比较大、比较浅，装的珠子就多；后来试着把碗捏深、捏小一点，反而只装得下两颗。

生25：我补充。碗捏得太浅，边上就矮，装珠子的时候水容易漫进来；捏得口高一点，碗虽然小了，装得反而多。

师：又是一条好证据——碗的大小、深浅、碗口高低，都会改变它排开水的多少。除了橡皮泥碗和铁船，生活里还有哪些地方也在用"改变形状、多占地方"这个办法，谁举个例子，和别人不一样的更好？

生14：我们老家河上有浮桥，是把好多个空的大铁桶绑在一起铺上木板，人走上去都不沉。

生15：游泳圈，吹足了气套在身上，人在水里就沉不下去了。

生16：还有独木舟，把大树中间挖空，人坐在里面划船。

生2：我想说潜水艇，它可以自己沉下去、又自己浮上来。

师：都是好例子。潜水艇要单独说一句——它靠的不是改变形状，而是往"肚子"里灌水和排水，改变自身的轻重，那是另一条聪明的路子，下节课我们专门研究它。

### 四、研讨小结（第37—40分钟）

师：快要下课了，我们一起看黑板右边的证据栏。今天这节课，我们一共收集到了哪几条关键证据，谁来念一念、补一补？

生17：第一条，橡皮泥球和碗一样重；第二条，铝箔团裹着空气也沉了；第三条，碗排开的水比球多得多；第四条，铝箔摊平和揉团一样重。

师：一条不多、一条不少。生3，听了这几条证据，把你现在的新想法跟大家说一说。

生3：我改主意了。不是空气像手一样把船托起来，是水在往上托。橡皮泥捏成碗以后并没有变轻，是它泡在水里的部分变大了，挤开的水变多了，水托它的力气就大了，大过它的重量，它就浮了。空气的作用是帮橡皮泥"占地方"，不是它自己在托。

师：能把一个想法改得有根有据，这是今天课堂上最了不起的事，掌声送给生3。（学生鼓掌）回顾一下这节课：一块只会沉的橡皮泥，在大家手里变成了一只能载玻璃珠的小船，靠的不是魔法，是改变形状、让它排开更多的水。最后留一个有挑战的问题——如果把这节课的清水换成很浓很浓的盐水，橡皮泥碗的沉浮会不会变化，为什么？

生18：我觉得会浮得更稳。因为盐水比清水重，同样被碗挤开一杯，这杯盐水更重，往上托它的力气就更大。

师：有理有据。死海的水特别咸，人可以躺在水面上看书，用的就是这个道理。最后一个问题——关于沉与浮，回家以后你还想研究什么新问题，说一个跟别人都不一样的？

生19：鸡蛋放在清水里是沉的，往水里一直加盐，它会不会浮起来，我想回家试试。

生20：我想研究鱼。鱼不改形状，它是怎么想沉就沉、想浮就浮的。

师：两个问题都记到"问题银行"里，下节课挑一个来研究。请各组把记录单收进科学文件夹，水槽里的水倒进桶里，桌面擦干净。下课。

生（齐）：老师再见。
