# 掌中实验室：课堂任务

每个实验按“先预测 → 动手试 → 说一说”展开。手势是改变实验条件的输入方式，屏幕上的物理量来自理想模型计算；工具不对学生姿态或回答打分。

## 掌中光路

### 小学：观察光的方向

1. **照亮目标**：预测镜子应向哪边转；用鼠标或张开的手转动镜面，让反射光照到目标；用自己的话描述发生的变化。
2. **镜子动一点**：保持光源不动，缓慢转动镜子，观察反射光的方向；说明光源、镜面、反射光中哪些发生了变化。
3. **先猜再看**：隐藏反射光，改变镜面方向；用手指出预计的反射方向，再显示反射光核对。

不要求记忆角度公式。需要用文字讲清“光碰到镜子会改变传播方向”，不是把动作完成当作知识掌握。

### 中学：验证反射规律

1. **从哪里量角**：显示法线，观察入射角与反射角；解释为什么不能从镜面开始量角。
2. **改变条件再验证**：至少选择三个不同镜面方向，记录两角；根据观测概括二者关系。
3. **预测反射光**：隐藏反射光，依据入射角画出预计方向；显示结果后解释依据。

模型为二维理想平面镜，入射点固定，入射光源固定。法线始终垂直镜面。工具只演示镜面反射，不模拟漫反射、折射或光强损耗。

## 掌中几何

### 小学：拓展探索

1. **数一数截面的边**：比较三角形、四边形预设，在右下角正视图中数边；指出形状来自切面与正方体的交集。
2. **转动视角**：保持切面固定，旋转观察正方体；对照二维截面解释“看起来变了”和“截面本身变了”的区别。
3. **移一移切面**：移动切面，观察什么时候出现截面、什么时候消失；理解“只碰到一个点”不是有面积的截面。

这是空间想象拓展，不宣称为所有小学年级的必学要求；按学生基础选用。

### 中学：寻找截面规律

1. **找到五边形**：使用五边形预设，数顶点并检查每条边位于哪个面；改变切面观察边数变化。
2. **找到六边形**：观察六边形预设，说明它与正方体六个面的关系。
3. **最多几条边**：先猜是否可能出现七边形，再尝试不同切法；解释一个平面与正方体每个面最多形成一条截面边，因此非退化截面至多六条边。

与立方体某一面重合的特殊位置单独提示。二维截面按真实平面坐标绘制，不把空间透视图中看似梯形的四边形直接判为梯形。

## 一次最小课堂试用

先选一个学段、一个实验、一个任务，控制在 5–8 分钟。让一位学生操作，其他学生先预测，最后让两位学生解释现象。判断工具是否有用的依据是学生能否解释规律，而不是是否成功做出了手势。
