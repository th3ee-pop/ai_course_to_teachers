# 掌中实验室

两套可独立使用的课堂实验：掌中光路、掌中几何。顶部切换实验和小学／中学；学段会改变教学任务、读数、标注及解释。默认进入小学光路，可直接用鼠标。

## 运行课堂版

1. 解压整个课堂版 ZIP，保留文件夹结构。
2. 电脑需已安装 Python 3。macOS 双击 `启动.command`；Windows 双击 `启动-Windows.bat`。
3. 保留启动窗口，浏览器会自动打开本地地址。默认端口 8770，被占用时自动选择后续空闲端口。
4. 结束后关闭启动窗口，或按 Ctrl+C。

也可在文件夹中运行 `python3 scripts/serve.py`；Windows 可用 `py -3 scripts/serve.py`。不要直接双击 dist/index.html，摄像头和识别模型需要本地 HTTP 服务。

运行所需的脚本、模型、WASM、字体都已打包，不依赖 CDN 或云端模型。无需账号；视频和识别计算仅在当前电脑内进行，应用不发送摄像头画面。首次使用前请确认电脑具备 Python 3 和可用的现代浏览器。

本机地址：
- 光路：`http://127.0.0.1:8770/#optics/primary`
- 几何：`http://127.0.0.1:8770/#geometry/secondary`

以启动窗口显示的实际端口为准。教学版在 macOS 的浏览器中完成验证；Windows 启动脚本已提供，尚未在 Windows 机器实测。

## 使用方式

**鼠标**：光路视窗左右拖动、方向键或滑杆转动镜面。几何视窗拖动或方向键旋转观察，三个滑杆改变切面。几何提供三／四／五／六边形预设；小学只显示三／四边形按钮，其他形状可作为拓展探索。

**摄像头**：切换输入方式后点击“开启摄像头”，允许权限，张开任意一只手。手掌转动控制镜面；手掌倾斜与上下移动控制切面。首次识别自动把当前手势对应到当前实验位置，也可点击“以当前手势为起点”重新对齐。保持手掌完整可见、缓慢移动；它是参数控制器，不评价手势正确与否。

**冻结**：锁定实验参数并暂停识别与视频播放；几何仍可旋转观察。显示法线、反射光、顶点等开关仍可使用。切回鼠标会释放摄像头；页面关闭也会释放。

**教学任务**：每个实验和学段各有两条界面任务，按“先预测 → 动手试 → 说一说”推进。中学光路默认隐藏反射答案。更多课堂活动见《教学任务.md》。工具不记录成绩，也不自动判定学生是否理解。

## 模型与教学边界

- 光路是二维理想平面镜反射，固定入射光源从左向右、入射点固定。反射方向由向量反射公式计算；入射角、反射角均相对法线。镜面方向读数是另一种角度，不能混淆。
- 几何采用正方体与平面的真实求交，三维空间以正交投影 SVG 呈现；拖动改变观察方向。透明线框便于看清内部关系，不模拟不透明实体的光照与遮挡。二维截面与空间图共享同一组顶点，按截面自身平面坐标等比例绘制。
- 与面重合、仅接触棱／顶点、完全离开正方体有单独提示。顶点字母按当前多边形排序，不表示运动中的固定追踪点。
- 单目摄像头的深度和手掌方向为模型估计，适合定性互动，不作为精密角度测量仪。精确条件用鼠标／键盘设置。静态左右手及完整模型管线已测试；真人操作的舒适度仍需在实际教室试用。
- 小学几何明确标为“拓展”，应按学生基础选用；不宣称所有小学年级都需要掌握截面。

知识核对：[反射定律](https://www.physicsclassroom.com/Class/refln/u13l1c.html)、[立方体截面](https://mathworld.wolfram.com/Cube.html)。识别能力参考 [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)。

## 开发与设计来源

OpenDesign Local Codex 先生成界面与交互设计，原始产物保存在 `design/`。正式实现保留其布局和教学流程，接入本地摄像头，修复 SVG 切换，并替换为经测试的反射／截面计算。原设计文档中的“模拟摄像头”仅描述归档设计稿，不代表正式版。

源代码项目使用 Vite、JavaScript／TypeScript 和本地 MediaPipe Worker。UI 沿用设计稿的普通 JavaScript；计算、识别和手势控制模块由 TypeScript 检查。正式渲染使用 SVG，不需要 WebGL。课堂 ZIP 只包含构建产物、启动脚本和说明；源码在项目目录。

开发命令：`npm ci`、`npm run dev -- --port 8770`、`npm test`、`npm run build`。测试使用 Node 24 的 TypeScript strip 模式。

- `src/physics.ts`：反射、目标命中、平面截面、预设。
- `src/main.js`：界面、教学流程、SVG 渲染、摄像头控制对接。
- `src/tracker.ts` / `public/tracker-worker.js`：设备生命周期和本地识别。
- `tests/camera.html`：真实识别模型的左右手与权限异常测试。
- `tests/live-camera.html`：完整应用的静态视频输入测试；只用于开发，不进入生产包。
- `tests/responsive.html`：390、1280、1440 像素的布局检查。

许可保留在 `public/licenses/` 与 `design/assets/`；随构建文件一起分发。具体测试证据见《验证记录.md》。
