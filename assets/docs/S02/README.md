# 教学观察台

两个可运行的讲座演示：四季探究与匿名过程回看；语言文化交流与表达修订回看。

## 启动

需要 Node.js 22.12+（开发测试建议24，本次使用24.13）。当前电脑的依赖和 `dist` 已准备好，可双击启动脚本或执行 `npm start`。复制到新电脑时先执行 `npm ci`，安装实时语音服务依赖；启动脚本也会在缺少依赖时自动安装。修改源码后重新构建：

```bash
npm install
npm run build
npm start
```

打开 http://127.0.0.1:8787 。也可双击“启动本机演示.command”。开发时使用 `npm run dev`。

## 三分钟四季体验与教师回看

1. 在运行服务的电脑上打开首页，点击“开启本场演示”。教师访问链接含管理凭证，不发给听众。
2. 教师页生成本场二维码。手机与电脑处于可互通的局域网时，用“启动局域网演示.command”运行服务；检查二维码地址为电脑实际局域网地址，而不是127.0.0.1。
3. 听众选择同意记录或仅体验。记录仅覆盖日期、纬度、时刻、地轴、视角及播放的主动操作，自动动画不按帧记录。
4. 讲到评价时点击“展开过程证据”。按匿名会话回看事件序列、操作前后条件和讲师解读框架；点击“重现情境”可恢复当时的四季画面。回放不会增加操作记录。
5. “查看预制样例”是独立的固定数据视图，明确标注，不会写入本场。
6. 参与者可停止并删除自己的记录；教师可导出记录或结束并清除本场。

状态存在服务内存中，每场最多500个体验会话、2万条操作，每会话最多1000条。最长4小时，到期自动清除；服务重启会清空全部场次。导出到电脑的JSON文件不会自动删除，由讲师管理。无实名账号、浏览器指纹和IP访问日志。底层网络连接仍会接触IP地址，本项目没有承诺技术上绝对无法识别。只按确有需要的范围收集。

监听0.0.0.0会让同一网络设备访问服务；教师汇总与删除需要秘密访问凭证，创建场次和真实模型调用仅允许本机。没有自动开通公网、隧道或云端部署。代理来源不能获得本机管理身份；不建议直接用反向代理对公网开放此演示服务。学校网络的设备隔离、防火墙可能阻止扫码，需现场用实际手机验证。

## 语言文化演示

- 两种虚构但具体的交流任务：共读角介绍、一次端午主题活动介绍。
- 中文与英文分别可用。资料限定本班／本次安排，不代表全部文化。
- 默认三轮预演：点击“填入本轮预演台词”再发送。来访者按固定脚本回答，界面持续标注，不会根据输入推理。
- “查看表达变化”比较第一次与最近一次表达，并提供事实、待判断、缺少证据和后续教学四栏；不是自动评分。
- 可朗读消息，并支持下述语音输入和逐轮语音对话。浏览器识别与系统朗读的可用性取决于设备、网络和权限。
- 离开页面会尝试清理服务器对话；最迟4小时过期。导出文件由讲师管理。

### 语音输入与语音对话

开始一段交流后，可选择：

1. **语音输入**：允许麦克风后说一句话，停顿结束识别，校对文字，再点击“发送表达”。
2. **开启语音对话**：说话 → 停顿后自动发送最终识别文字 → 播放对方回应 → 自动进入下一轮收音。中文与英文跟随本段的表达语言。播放时关闭麦克风，避免收进电脑自己的声音。
3. **停止语音**：随时停止收音或播放，不会因已在等待的模型回应重新开麦；已发送的请求仍可返回文字。离开页面或切到后台也会停止。无语音、权限失败或网络错误后需主动重试，不会循环申请权限。

这是基于浏览器语音识别、聊天接口、系统朗读的逐轮对话，不是支持同时说听和随时插话的全双工实时音频通话。后一种体验需要另行接入专门实时音频服务。预演模式始终使用固定脚本；真实模型配置后才会按识别文字生成回应。

**运行条件**：讲师电脑可用 `http://127.0.0.1:8787`；手机普通局域网 HTTP 地址禁用网页语音输入，需要 HTTPS。浏览器没有提供识别接口时，按钮会禁用并提示改用文字或系统键盘听写。提供接口也不保证识别服务实际可达，须在演讲设备及网络上试说。部分浏览器的识别会将音频交给浏览器厂商的服务处理；本系统不接收或保存音频，只把最终识别文字按当前对话模式处理。详见 [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)。

## 接入真实模型（可选）

### 豆包端到端实时语音（已接入）

打开 `http://127.0.0.1:8787/#/realtime`，或从语言交流页点击“豆包实时语音通话”。选择情境和中文/英文，同意音频处理，点击“开始实时通话”，允许浏览器使用麦克风即可。

此入口直接使用豆包语音模型，不依赖下方的通用文字模型配置。模型根据本次情境及声音回应，实时显示转写和模型文字，支持在检测到新语音时停止当前播放。结束、离开前台或切换页面时关闭麦克风和连接；单次最多5分钟、同一服务最多1场通话，防止演示结束后持续调用。建议使用耳机实测回声与插话体验。

本机 `.env` 使用 `DOUBAO_APP_ID` 和 `DOUBAO_ACCESS_TOKEN`，只由服务端读取；不进入网页、URL、导出文件或日志。旧版官方接口的公共 App Key 与 Resource ID 在服务端固定，不是用户的 Secret Key。本轮按官方文档接入 O2.0（`1.2.1.1`）版本，中英文选用各自支持的音色，输入16kHz PCM16，输出24kHz PCM16。[官方接口文档](https://docs.volcengine.com/docs/6561/1594356?lang=zh)

此入口仅讲师本机 localhost/127.0.0.1 可发起，不对扫码听众开放付费调用。音频经本机转发到火山引擎，本系统不存盘；第三方处理及保留按其服务条款执行。文字存在本页内存中，刷新后清空，导出的JSON由讲师管理。被打断的回应会标注，文字不等于参与者已听到的完整内容。

已用真实服务验证中文、英文短文本获得流式语音；另用9秒合成中文测试音频经本机转发获得正确转写和新的模型音频回应。这不能替代真人麦克风、浏览器实际扬声器和教室回声的实测。接口可用不等于教学成效已验证。

### 通用文字模型＋浏览器语音（原逐轮模式）

复制 `.env.example` 为 `.env`，只在本机文件配置以下字段，切勿在聊天或网页输入密钥：

- `AI_CHAT_URL`：服务商提供的完整兼容 `chat/completions` 地址。
- `AI_MODEL`：服务商模型ID。
- `AI_API_KEY`：服务端调用密钥。

随后重启服务。“真实AI对话”在本机讲师界面可选。请求使用非流式聊天协议，读取 `choices[0].message.content`。仅支持HTTPS服务商地址或本机HTTP模型服务，未适配特殊签名、非兼容协议或流式响应。模型收到情境资料及本次对话；不把四季操作记录自动发往模型。

真实模型超时30秒、单次输入最多2000字、每段最多12轮；失败会明确提示，不自动降级成脚本，不把失败请求算作完成轮次。服务商密钥不会返回浏览器。额度费用由所选服务商决定。

## 检查

```bash
npm test
npm run build
```

显示统计是会话数，不是去重人数；刷新后重新加入会产生新会话。

测试包含事件验证、跨访客汇总、重试去重、撤回、到期清理、接口鉴权、跨站请求拒绝、预演轮次与模拟模型服务成功/失败契约。模拟服务测试不是对真实服务商的联网实测。

语音状态机测试使用 Node.js 24 原生 TypeScript 擦除运行，开发及测试建议使用 Node.js 24；已构建系统的启动要求不变。新增9项语音测试使用模拟麦克风与播放器，覆盖最终/临时识别、停止后的迟到事件、回应失败、轮次结束、超时和权限失败，不能替代实际收音测试。

## 文件组织与来源

- `src/`：观察台、体验容器、语言交流与教师回看。
- `server/`：本机HTTP服务、临时场次与模型适配。
- `public/seasons/`：作者“四季循环”v2副本；`observer.js`为新增操作适配，原始专著目录未修改。
- `tests/`：领域与HTTP集成验证。
- `design-reference/`：OpenDesign 使用 Local Codex 完成的完整设计原稿。正式页面复用其设计变量、字体、按钮规范和首页四季意象，并另行接入真实功能。该目录的独立 HTML 是静态设计参考，其中的样例数据和二维码不用于现场加入。
