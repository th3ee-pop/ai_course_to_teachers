## 实现决定

1. **不复用设计稿运行时**（deck-stage.js / support.js / image-slot.js 依赖 Omelette 的 React 解析层），自写 `deck.css` + `deck.js`：1920×1080 舞台等比缩放；翻页、目录、全屏、讲者视图、翻页停视频、快捷键避让互动元素、hash 定位。
2. **讲者视图**用 window.open + postMessage，不用 BroadcastChannel，保证 file:// 下可用。
3. **设计系统令牌**（Industry DS）抄成 CSS 变量；蓝图角标（blueprint/corner）按 styles.css 原样实现；`image-slot` 换成普通 `.slot`，有图放 `<img>`，无图显示带"待放入实拍照片"标签的占位。
4. 设计稿的三个开关 showIds / showLocator / showKeyframes 改为快捷键 I / L / K。
5. 文案、数字、出处、示例标签全部按设计稿逐字保留；引用政策只用已核对的那一句。

## 基础设施（P0）

- `build/build.py`：`validate` 检查每页的 section 契约、必备属性、素材引用、分步计划与 `.reveal` 的一致性；`assemble` 把 `pages/*.html` 按 ID 顺序拼进 `build/template_head.html` / `template_tail.html` 生成 `index.html`，并更新 `build/manifest.json`。
- `pages/` 每页一个文件，契约：`section.slide[.dark][data-id][data-title][data-module][data-stage][data-kind=主线|备选][data-template][data-status]` + `.hdr` + `h2.title` + `p.sub` + `<!-- BODY:START/END -->` + `.foot` + `<aside class="notes">`。生成页顶部保留 `<!-- PLAN … -->` 注释记录分派计划。
- `deck.js` 新增：`.reveal[data-step]` 分步（→/空格/PageDown 先走完本页步骤再翻页，A 键一次全显）；`?all` 参数全显所有步骤（用于 QA 与打印）；`.embed[data-src]` 惰性 iframe，翻到该页才加载；`[data-config]` 从 `config.js` 读地址生成二维码（`components/qrcode.min.js`），地址为空显示占位；快捷键在 input/textarea/select/button/a/video/audio/iframe/contenteditable 及 `.anim[tabindex]` 内不拦截。
- `components/map433.js`（4＋3＋3 总图）与 `components/cycle.js`（循环图）：无依赖、脚本注入样式；用法见 `components/README.md`，`components/_test.html` 可单测。三问与三种角色不画连线。
- 16 个模板 T01–T16 写在 `build/gen_pi.py` 里；12 个“单句陈述页”（P003 P006 P010 P011 P025 P037 P050 P057 P065 P069 P082 P083）用统一的大字居中版式。
- 字体本地化：`build/fetch_fonts.py` 抓取 Google Fonts 的 Noto Sans SC / Noto Serif SC / Barlow Condensed 子集到 `assets/fonts/`（208 个文件，约 10 MB，`assets/fonts/fonts.css`），`deck.css` 只引本地文件，断网可用。
