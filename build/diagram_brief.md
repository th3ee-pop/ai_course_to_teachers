## 二、目标

图要**美观、生动、真实**，并且**在页面中占比合适**：

- 示意图区域至少占正文区（`.body`）宽度或高度的 55–65%；不再出现"小图 + 大空白"。
- 图内任何文字 ≥ 24px（按 1920×1080 页面像素计；若用 SVG，请按 viewBox 与实际渲染尺寸换算），主标签 28–32px。
- 图标有面、有层次：用填充 + 描边 + 轻阴影/双色，不再用裸线拼形。
- 箭头用 `<marker>` 定义真正的箭头头部，线宽 3–4px，回环/返回线走图外沿或走下方，绝不穿过文字。
- 模拟 UI 页要像真实产品：对话输入框（圆角、占位符、发送按钮）、"思考/步骤"卡片、代码块（等宽字、行号、深色或浅灰底）、运行日志、产物缩略图（像 Word 页/表格/网页的小预览），并保留原有 分步/播放/重置 逻辑。

## 三、风格与素材

- 设计体系："Industry/蓝图"风：钢蓝 `--accent #5980a6`、深钢蓝 `--accent-dark #416180`、浅蓝 `--light-blue #94bce3`、面 `--surface #dfe9f3`、页面底 #f2f2f3、文字 #1d1f20、警示色 #b2603f、深色页底 #1d2d3d。字体已本地化：Noto Sans SC（正文）、Noto Serif SC（标题）、Barlow Condensed（数字/英文标签）。
- **图标库**（可用）：`/Users/chensirui/Desktop/ppt素材/`，约 520 张 512×512 透明 PNG，彩色扁平插画风，分文件夹 01_AI与科技 / 02_教育学习 / 03_数据与分析 / 04_办公商务 / 05_人物图标 / 06_生活方式 / 07_其他图标 / 未命名文件夹。用 `ls` 浏览文件名挑选。
  - 用法：复制需要的 PNG 到课件 `assets/img/icons/`（用英文/拼音改名，如 `teacher.png`），页面用相对路径 `assets/img/icons/xxx.png` 引用。
  - 风格冲突处理：图标库是多彩插画风，与钢蓝线条体系有冲突。建议只作点缀（每页 3–5 个），放在白色/浅蓝圆角卡片里统一底，尺寸统一（如 96–128px），必要时 `filter: saturate(.75)` 降饱和；不要满屏彩色图标。
  - 也可以完全不用图标库，自己写带填充的内联 SVG（推荐用于流程线、漏斗、泳道、日影这类结构图）。
- 优先**内联 SVG 或 HTML/CSS 构图**写在页面 `<!-- BODY -->` 内，这样文字可用页面字体、可分步 reveal；也可写新的 `assets/svg/<pid>_v2.svg`，但文字需 ≥24px 折算。原 SVG 文件不必删除。
- 深浅色：所有页都是浅色页，除非页面本身 `data-template` 是 dark。

## 四、硬性红线（违反即返工）

1. **页面文字与脚本逐字一致**（`../19_逐页内容脚本/审校后页面中间稿.json`）。示意图内只允许出现：原页面已有的文字；按钮（下一个/播放/重置）；标签（示意图 / 示例对话 / 角色模拟 / 理想模型，非实测数据 等，原页已有的保留）；坐标轴/图例/UI 占位符文字。**不要新增讲解性文字**。UI 模拟中的示例任务文本、代码文本，沿用页面原有的（如 P013 的 TASK/CODE 常量）。

3. 三问（教学设计/课堂实施/教学评价）不与三角色连线。
4. 只改分配给你的 `pages/<ID>.html`，新增素材放 `assets/img/icons/` 或 `assets/svg/`；不改 deck.css、deck.js、components/、其他页。
