# 现场演示前提清单（2026-09-15 初稿）

每个演示三段：**引入问题**（这一页为什么要演示它，来自脚本"典型需求"）→ **生效前提**（演讲前逐项勾）→ **兜底**。
同样内容压缩后写进对应页的讲者备注。事实来源：各系统 README / 课堂版说明 / 验证记录；标 ⚠ 的是文档明确写"待现场复演"的点。

## 通用前提（所有演示）

- [ ] 讲师电脑：Chrome 或 Edge 近期版本；Python 3；Node.js 22.12+（观察台）。
- [ ] 所有演示系统在**授课电脑**上提前启动一遍并留着终端窗口，不要依赖现场双击。
- [ ] 投影分辨率 1920×1080；课件用 `?all` 参数可整页显示分步内容。
- [ ] `config.js` 六个地址已填；只填参与者地址。
- [ ] 每个演示都有兜底录屏（见 `plan/资源清单_v1.md` 第三节），放在 `assets/video/`。
- [ ] 决定演示方式：**A 本机演示**（投影讲师电脑，听众看）或 **B 局域网扫码**（听众手机参与）。B 需要现场用真实手机验证一次，学校网络的设备隔离和防火墙可能挡住扫码。

- 兜底：`demo_siji.mp4`。

## 2. 教学观察台·四季采集与回看（P041 P066A P067 P090；备选 B22）

- 引入问题：老师想在课后回看"学生操作了什么、在哪一步改变了想法"，而不是只看结果（P066A 典型需求）。
- 生效前提：
  - [ ] 在 `04_演示系统/教学观察台` 双击"启动本机演示.command"（本机）或"启动局域网演示.command"（扫码），打开 `http://127.0.0.1:8787`。
  - [ ] 点"开启本场演示"，教师页生成本场二维码；**教师链接含管理凭证，不投影、不发给听众**。
  - [ ] 扫码方式：确认二维码地址是电脑的局域网 IP 而不是 127.0.0.1；手机和电脑同一网段；现场先用一部真实手机试扫。
  - [ ] 听众进入后选择"同意记录"或"仅体验"，只有同意记录的会话才会出现在回看里，演示前自己先用手机做 2–3 个会话，保证回看有数据。
  - [ ] 状态只在内存，**服务重启即清空**；一场最长 4 小时。演讲当天开一次就不要重启。
  - [ ] "查看预制样例"是固定数据视图，回看没有现场数据时可以切到它，但要说明是样例。
- 兜底：`demo_guanchatai_siji.mp4`；或直接用"查看预制样例"。

## 3. 教学观察台·语言文化交流（P051 P052 P053；备选 B10）

- 引入问题：学生用外语介绍共读角，需要一个可以反复练、能看到表达变化的对象（P051 典型需求）。
- 生效前提：
  - [ ] 同一服务（8787）。三种模式要分清：**固定脚本预演**（点"填入本轮预演台词"，不联网、不推理，最稳）／**通用文字模型**（需本机模型接口，只允许本机调用）／**豆包实时语音**（需网络与密钥）。
  - [ ] 现场建议用固定脚本预演；⚠ 真实语音接口"现场收音待复演"，会场麦克风与浏览器麦克风权限要提前试。
  - [ ] 浏览器语音识别与系统朗读依赖设备与网络；Chrome 的识别在部分网络下不可用。
  - [ ] 要演示"查看表达变化"，至少要先完成两轮表达。
- 兜底：`demo_guanchatai_talk.mp4`。

## 4. 掌中磁场（P042B；备选 B07）

- 引入问题：右手螺旋定则讲了很多遍，学生还是把手的握向和电流方向对应不起来（P042B 典型需求）。
- 生效前提：
  - [ ] `03_工具与技术/掌中磁场` 双击"启动.command"（Python 3 本地服务），**不要直接双击 dist/index.html**，摄像头需要 localhost。
  - [ ] 先用"鼠标演示"反转电流讲清 N/S 与电流方向，再切"摄像头跟手"。
  - [ ] 浏览器允许摄像头；右手完整入镜、拇指伸直、四指自然弯曲；低光、侧面、握拳遮挡会丢手。⚠ 真人摄像头握拳与连续转动"待复演"，今晚在酒店先试一次。
  - [ ] 讲解口径：跟手不判断四指卷曲是否正确、不评分；磁感线只表示方向不表示强弱；反转电流后要重新用右手定则核对。
  - [ ] 断网可用，模型随包。
- 兜底：`demo_cichang.mp4`；或只用鼠标模式。

## 5. 掌中实验室·光路 / 几何（P042D P042F；备选 B05 B06 B23）

- 引入问题：光路是"先预测反射方向再验证"；几何是"正方体被平面切出什么截面"（P042D/F 典型需求）。
- 生效前提：
  - [ ] `03_工具与技术/掌中实验室` 双击"启动.command"，默认端口 8770，被占用会顺延，以启动窗口显示的端口为准；光路 `#optics/primary`，几何 `#geometry/secondary`。

  - [ ] 摄像头：张开一只手，首次识别自动对齐，可点"以当前手势为起点"重对齐；手掌完整可见、缓慢移动。
  - [ ] 精确角度用鼠标/键盘设置，手势只是定性控制器。
  - [ ] 断网可用；仅在 macOS 验证过，Windows 未实测。
- 兜底：`demo_guanglu.mp4`、`demo_jihe.mp4`；或鼠标模式。

## 6. 生态岛行动（P042H；备选 B08 B23）

- 引入问题：小组用同一起点做对照实验，改变一个条件看鹿群与草地的变化（P042H 典型需求）。
- 生效前提：
  - [ ] `04_演示系统/生态岛行动` 双击"启动.command"，打开 `http://127.0.0.1:8780/`；需要 WebGL；不要直接双击 dist/index.html。
  - [ ] 断网可用，不需摄像头和账号。进度保存在该浏览器该端口，换端口等于换存档。
  - [ ] 演示流程约 5 分钟：播放原岛 24 轮 → 写预测 → 6 点预算最多 3 项行动 → 再跑 → 比较。现场时间不够就只放"原岛 24 轮"再切到已跑好的方案对比。
  - [ ] 讲解口径：每轮是模型时间不是真实一天；能量耗尽是死亡不是离岛；改变多个条件只能评价整套方案；没有"最高分"。
- 兜底：`demo_shengtaidao.mp4`。
