| 页面单位 | 每页一个片段文件 `pages/<ID>.html`（只含 `<section class="slide">…</section>`），`build.py` 按脚本顺序拼成 `index.html`；24 页备选放在 P096 之后的“备选片段”组，目录分组显示，讲者视图可跳转。 |
| 骨架先行 | 主控用脚本从 JSON 生成每页骨架（`section` 属性、定位行、页码、标题、页脚、`<aside class="notes">` 讲者备注＋资源链接），**agent 只写正文区**。听众文字不允许改写，只允许排版。 |

### ② 分阶段呈现（104 页）——统一规则，不逐页发明

- 默认规则：`audience.blocks` 每条 = 一步，按脚本顺序；标题、副标题、页脚首屏即显。JSON 的 `cat2_reveal` 已列出每页步骤名。
- 例外：大字引文页（T02，14 页）与封面/结束页不分步；P016 副标题拆成三步；对话页按“轮”分步；对照页先左后右再结论；三问卡三步；P059 用计数与条形动画代替静态分步。
- 不做“飞入/旋转”等 PPT 式动效，只用 350ms 的淡入＋上移 12px；停讲页最后一步可用 `reveal-focus` 把前面步骤压淡。

## 4. 子代理合同（所有执行器共用）

1. **只写正文区**。骨架已含 `section` 属性、`.hdr .locator/.pid`、`h2`、`.sub`、`.foot`、`<aside class="notes">`；正文写在 `<!-- BODY -->…<!-- /BODY -->` 之间。
2. **文字零改写**。`audience.blocks` 的 label 与 text 必须逐字出现（校验脚本会做子串比对）；可以加视觉标签（“示意图”“示例对话”“AI 生成试样”“待放入实拍照片”），不能加脚本没有的事实、数字、引语。
3. **设计令牌**：只用 `deck.css` 变量与工具类（`.serif .cond .blueprint .cols .card .reveal .tag .embed .link-card .photo-slot`）；1920×1080 内边距 84/110；正文 30–40px；行高 1.6；一页正文不超过 4 条块。
4. **资产只用 JSON 里给的 id**；路径由骨架注入为相对路径；找不到的资产用 `.photo-slot` 占位并写明“待放入…”，禁止生成或引用外部图。
5. **分步**：按 `cat2_reveal` 的顺序给元素加 `class="reveal"`；不自创其它动效类。
6. **内嵌**：iframe 用 `<div class="embed" data-src="…">`（deck.js 负责懒加载与卸载），并给 `data-fallback` 截图；视频 `preload="metadata"`、不自动播放；外链卡片用 `<a class="link-card" data-config="observatory.participantUrl">`。
7. **讲者备注不动**（已由骨架从 `production.speaker_notes` 与 `resources` 生成）。
8. **交付格式**：只返回该页片段文件内容；不返回解释。

## 5. 工作流（顺序与并行）

```
P0 基建（主控，1 次）

   build.py：JSON→pages/*.html 骨架；pages→index.html；validate.py（文字子串、属性、资产存在、链接存在）

   复制：S01 目录、S07/S08/S09/S10/D07/S13 单文件、3 段视频、17 张已有截图

   Codex：12 张 SVG（C1）
P2 生成（并行）
   pi S1–S9（串行批次，每批 3–5 页）      opus O1 / O2 / O3（3–4 个代理并行）
   主控 X0：16 页加 reveal/截图
P3 组装与校验：build → validate → 浏览器逐页截图（1920×1080）→ 抽检 20 页人工看
P4 交接：records/制作记录、README 更新；`plan/pages_plan.json` 回写 status
```

预估：P0 半天；P1 半天（采集依赖你确认 Q3）；P2 约 1 天（pi 91 页 ≈ 25 批 × 2–4 分钟；opus 4 组并行）；P3 半天。
